# Changelog

## 0.1.0

First public release.

- Save a LinkedIn profile as a PDF résumé, generated in the browser.
- Experience with multiple roles, descriptions and company logos; education; languages; photo.
- Full lists loaded from the profile's "Show all" pages.
- Text in Latin (including Vietnamese), Greek and Cyrillic scripts. If other scripts can't be drawn, the popup says so.
- Optional anonymous diagnostics, which can be turned off in Options.
